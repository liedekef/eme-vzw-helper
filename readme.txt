VZW compliance checklist, legal filings and UBO management as an extension of Events Made Easy.

== Description ==

EME VZW Helper extends Events Made Easy with functionality for Belgian nonprofit organizations (VZW):

* Compliance checklist with periodic reminders
* Legal filings (Form 1 & 2, declaration of management ban)
* Statutes amendment
* UBO management (Ultimate Beneficial Owners)
* Management of board mandates

The plugin requires the Events Made Easy plugin.

== Installation ==

1. Install and activate the Events Made Easy plugin first.
2. Upload the `eme-vzw-helper` folder to `/wp-content/plugins/` or install through WordPress.
3. Activate the plugin and configure it via VZW Helper in the admin menu.
